# Shared layouts

## `src/App.tsx`
Application shell: authenticated layout with responsive sidebar, sticky header, routed view content, and global contact/import modals.

## `src/components/layout/Sidebar.tsx`
Persistent navy navigation with active state, role-aware administration items, user controls, and logo slot.

## `src/components/layout/Header.tsx`
Persistent white top bar with page title, secondary actions, notifications, and the primary campaign action.
